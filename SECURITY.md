# Security Policy

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub Issues.**

Use the private channel below:

- **GitHub Security Advisory**: <https://github.com/Trace520/ultimate-security-audit/security/advisories/new>

## Response SLA

| Stage | Timeline |
| :--- | :--- |
| Initial response | Within 72 hours of report |
| First assessment (accepted / triaged / informational) | Within 7 days |
| Default remediation window | 90 days |

## Scope

This policy applies to the skill files, examples, and tooling in this repository.

It does **not** cover the third-party tools referenced in `docs/toolchain.md` (Playwright, webcrack, Ghidra, jadx). Please report issues with those tools to their respective maintainers.
